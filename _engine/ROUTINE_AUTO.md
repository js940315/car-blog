# 자동화 루틴 지시서 (매일 새벽 클라우드 에이전트용)

이 문서는 매일 자동으로 자동차 포스팅을 생성하는 **클라우드 루틴(claude.ai 스케줄)**에 넣을
지시 내용이다. 아직 **스케줄에 연결하지 않은 준비 상태**다 (Publish + Claude App 접근권한 후 연결).
발행 자체는 네이버 정책상 수동 복붙 — 루틴은 output/ 커밋까지만 한다.

---

## 매일 절차 (요약)
1. RSS 4개에서 최신 기사 수집
2. 중복 회피(state/seen_articles_auto.json) 후 **10건을 채워** 선별 (카테고리 분산)
3. 각 기사를 PROMPT_AUTO_V1.md 규칙으로 생성
4. 생성 결과를 build_posts 입력용 articles.json으로 **조립**(아래 조립 규칙)
5. `python _engine/build_posts.py _engine/articles.json {MMDD}` 실행
6. build_report.json에 problems가 비어있는지 확인 → 있으면 재작성
7. seen_articles_auto.json 갱신 후 output/ 커밋·푸시

## ★★ 소재 선별 제1원칙 — 독자가 '살 수 있는 차'를 쓴다 (2026-08-08 확정)
조회수 부진 원인 분석 결과, 홈판 상위 블로그(아워오토·곰도라·원동욱·범범)는 최근 40개 제목이
거의 전부 **국내 판매 중인 구체 모델 + 가격/할인 숫자 + 경쟁 모델 저격**이었다.
반면 우리는 해외 정책·모터스포츠·미출시 브랜드가 많아 "읽어도 내가 살 게 없는" 글이 됐다.
(실측 2026-08-08 생성분: 호주 정부 위치데이터·F1 해밀턴·쉐보레 간판·루시드 연기 등 10건 중 국내 구매 소재 거의 0)

**강제 규칙**
1. **하루 10건 중 최소 6건은 아래 '프레스 보유 23모델' 중 하나를 주인공으로** 삼는다.
   팰리세이드·그랜저·싼타페·투싼·코나·아반떼·아이오닉5·아이오닉9·**쏘나타·스타리아**(현대)
   쏘렌토·카니발·스포티지·EV6·EV9(기아) / GV80·G80·G90·GV70(제네시스)
   테슬라 모델Y·모델3 / **BMW 5시리즈·포르쉐 카이엔**(2026-08-08 4차까지 누적)
   → 이 모델들은 제조사 프레스 사진이 있어 사진 품질이 자동으로 최상급이 된다.
   → 현대 8모델은 '실사'(모터쇼·국내 목격 컷)도 있어 빌더가 알아서 섞는다.
2. **국내 판매 모델 우선.** 해외 전용 모델·해외 정책·모터스포츠·미출시 브랜드는 **합쳐서 하루 2건 이하**.
3. 제목에는 가능하면 **모델명 + 숫자(가격·할인·판매량)**를 넣는다. 추상적 관점 제목만으로는 클릭이 안 난다.
4. 소재가 부족하면 속보 대신 **에버그린 구매 정보**로 채운다:
   모델 비교(쏘렌토 vs 싼타페), 유지비·연비, 감가·중고 시세, 트림·옵션 선택, 구매 타이밍.

## 선별·중복 회피
- 최근 3일 내 다룬 이슈와 제목·핵심소재가 겹치면 스킵하거나 완전히 다른 관점으로만 진행.
- **목표는 하루 10건**. 8개 카테고리를 한 바퀴 돈 뒤(카테고리당 1건), 10건이 안 되면
  기사가 풍부한 카테고리에서 **카테고리당 최대 2건까지** 더 뽑아 10건을 채운다.
  · 같은 카테고리 2건째는 **소재(모델·기업·사건)가 확실히 달라야** 한다. 같은 이슈를
    관점만 바꿔 두 번 쓰는 건 유사문서로 취급되니 금지.
  · 그래도 10건이 안 되면 무리해서 지어내지 말고 **가능한 만큼만** 만들고,
    마지막 알림에 "몇 건/왜 못 채웠는지"를 명시한다(기사 부족은 정상적인 상황).
- ★ **셀럽·연예인차는 RSS 기사에 의존하지 않는다 — 매일 1건 필수 생성(에버그린)**.
  "손흥민이 타는 그 SUV" 같은 소재는 오늘 뉴스가 아니어도 언제든 통하는 상시 소재다.
  RSS에 셀럽 기사가 없다는 이유로 **이 카테고리를 빠뜨리지 말 것**(누락 사고 있었음).
  · 소재는 **확인된 공개 사실만**: 공식 앰버서더·협찬 계약, 본인·소속사 발표, 본인 인터뷰/방송 발언,
    다수 언론이 보도한 사실. 필요하면 WebSearch 로 근거를 확인한 뒤 쓴다.
  · 커뮤니티 목격담·추측은 사실로 단정 금지("~라는 이야기가 나온다" 3인칭 인용까지만).
  · ★ **인물 사진은 필수다 (2026-08-09 사용자 지시)**. 기사를 쓰기 **전에** 먼저 소싱한다:
    `python _engine/build_people_library.py --add "<영문 정식표기>" --name <한글명>`
    → 1번 썸네일 photo_category 에 그 한글명을 넣는다.
    → **못 구하면 그 인물 기사를 버리고 사진이 있는 다른 인물로 바꾼다.** 차 사진으로 때우지 않는다.
    → 빌드가 잡아낸다: 셀럽 기사인데 인물 사진이 없거나 썸네일이 인물이 아니면 `!!!!` 배너에 뜬다.
    ※ Commons 가 429(요청 과다)를 던지면 몇 분 뒤 재시도. 얼굴이 6% 미만인 단체컷은 자동 폐기된다.
  · 매일 같은 인물을 반복하지 말 것(state/seen_articles_auto.json 에 다룬 인물도 기록).
- 다른 카테고리도 그날 RSS가 빈약하면, 시의성이 낮은 **에버그린 관점 기사**(비교·유지비·감가·
  구매 타이밍)로 대체할 수 있다. 억지로 속보를 지어내지 않는다.

## ★ articles.json 조립 규칙 (PROMPT 출력 → build 입력 변환)
build_posts.py는 아래 필드를 읽는다. PROMPT_AUTO 출력을 이 형태로 옮기고, 특히 **images[] 카드 스펙**을 채운다.

```json
{
  "title": "...", "intro": "...",
  "body_paragraphs": ["소제목/문장/【N번 사진】 마커 배열"],
  "editor_comment": "[에디터 Comment] ...",
  "closing_question": "여운형 질문(선택)",
  "disclaimer": "구매판단 영향 카테고리면 표준 면책, 아니면 \"\"",
  "hashtags": ["8개"],
  "images": [ ...카드 스펙... ]
}
```

### 이미지 구성 = 8장 한 세트 고정 (썸네일 1 + 사진 7)
경제판 카드뉴스(막대·숫자·정리)를 쓰지 않는다. **실제 차 사진이 주력.**
- **1번 = 썸네일**: `thumbnail`, photo_category=모델명.
  **글자를 얹지 않는다** — 빌더가 원본 사진을 정사각으로 잘라 그대로 쓴다(2026-08-08 개편).
  홈판 상위 블로그는 썸네일에 텍스트 없이 고화질 실물 사진으로 승부한다.
  - 예외: 상장 종목 주가·실적이 핵심 주제일 때만 `stock_thumbnail`.
- **2~8번 = photo_card 7장**: 실물 차 사진. **그 중 실내(인테리어) 최소 2장.**
  · 권장: 외관 → 외관 → 실내 → 외관 → 실내 → 외관/맥락 → 정리
  · summary_card를 쓰려면 8번 1장만 대체(선택). 기본은 8장 다 사진.
  · **캡션에 각도 특정 금지**: photo_card는 버킷에서 순환 선택돼 앞/뒤/측이 매번 다르다.
    eyebrow·headline에 "앞모습/뒤태" 같은 각도 단정 대신 "존재감·디자인·실루엣·실물" 등 각도 무관 표현을 쓴다.
  · depth 있는 모델(팰리세이드·쏘렌토·싼타페·GV80·EV6·테슬라Y 등)은 6~7장까지 늘려도 반복이 안 난다.
- **데이터카드(bar/number/rank/stock)는 원칙적으로 안 씀.** 뚜렷한 비교수치가 꼭 필요할 때만 5장 중 1장.
- 검증: 5장이면 validate가 2번 슬롯을 photo_card로 요구하므로, 1=thumbnail·2=photo_card 순서 유지.

### ★ 제조사 프레스 사진 (최우선 사용)
`*_press*` 파일은 제조사 공식 스튜디오·광고 컷이라 워터마크·번호판·딜러광고가 없다.
pick_photo 가 **프레스 사진을 무조건 먼저** 고르므로, 아래 모델은 photo_category 만 맞추면
자동으로 최고 품질이 나간다(2026-08-08 기준 14모델 98장):
  현대: 팰리세이드·그랜저·싼타페·투싼·코나·아반떼·아이오닉5·아이오닉9
  기아: 쏘렌토·카니발·스포티지·EV6·EV9
  제네시스: GV80
※ 새 모델 추가는 `python _engine/build_press_library.py --list` 참고. 모델 페이지에서
  vr360 코드(현대) / dam 경로(기아) / CDN 자산ID(제네시스)를 뽑아 PRESS 에 등록한다.

캡션이 "카카오톡 공유로 응모"인데 차 사진을 붙이면 센스 없어 보인다. 아래 버킷을 쓴다.

| 카카오톡·SNS·공유 이벤트 | **SNS공유** (메신저 앱 아이콘·스마트폰) |
| 홈페이지·온라인 응모·앱 신청 | **온라인구매** (노트북·웹사이트 화면) |
| 계약서·서류·약관 | **계약서류** |
| 중국 자본·중국 업체 | **국기중국** (오성홍기) |
| 미국 관세·미국 정부 | **국기미국** |
| 유럽 규제·EU·독일 | **국기유럽** |
| 가격·시세·할인 금액 | **돈가격** (지폐·계산기) |
※ 6장 중 1~2장만 맥락 이미지로 쓰고 나머지는 실차로 채운다(자동차 블로그의 중심은 차).

### 실내(인테리어) 버킷
- 실내고급(제네시스 프리미엄 실내), 실내운전석(아이오닉5·EV9 콕핏).
- 외관 모델과 **급이 맞게** 쓴다(대형 프리미엄 기사 → 제네시스 실내, 전기 SUV 기사 → 아이오닉·EV 실내).
  실내는 정확히 같은 모델이 아니어도 '같은 급의 현대적 실내'면 허용(외관 hero는 반드시 그 모델).
- **브랜드 로고 불일치 금지**: 타 브랜드 로고가 드러나는 실내를 쓰지 않는다. 기사 차 브랜드에 맞춰 고른다:
  · 제네시스 → 실내고급   · 현대·기아(전기차 등) → 실내운전석   · 벤츠 → 실내벤츠
  · BMW → 실내BMW   · 테슬라 → 실내테슬라   · 그 외 수입/프리미엄 → 실내수입
  ※ 실내는 stock(Pexels/Unsplash) 컷이 깨끗하다. wiki 실내는 올드카가 많아 유의.

### ★★ 썸네일 = 제목의 주인공 (최우선 규칙, 위반 시 그 기사 재작성)
1번 썸네일 사진은 **제목에 등장하는 핵심 소재 그 자체**여야 한다. 이게 어긋나면 독자가 속았다고 느끼고 바로 이탈한다.
- 제목에 **모델명**이 있으면 → 그 모델 버킷. (GV90 기사에 아이오닉5 ❌ / 아이오닉9 기사에 G90 ❌)
- 제목에 **인물명**(정의선·CEO·연예인)이 있으면 → assets/portraits/ 인물 사진을 `photo`로 직접 지정.
  인물 사진이 없으면 → 그 인물의 소속 브랜드 차·본사사옥·발표행사 사진(공장 배경은 최후).
- 제목이 **수출·판매·물량**이면 → 산업수출(자동차 운반선·선적) 사진. 노을·바다만 나오는 컷 금지.
- 제목이 **노조·파업·시위**면 → 노조시위 사진. 그냥 빌딩 ❌.
- **브랜드 절대 일치**: 제네시스 기사엔 제네시스, 현대엔 현대, 아우디엔 아우디. 타 브랜드 차 금지.
- 폴백 사다리(위에서부터 시도): ① 정확한 모델 → ② 같은 브랜드 동급/상위 모델
  (GV90→GV80/G90, 아이오닉9→EV9/아이오닉6) → ③ 그 브랜드 아무 모델 → ④ 산업/테마 사진.
  ②~④로 내려갈수록 캡션은 그 차를 단정하지 말고 일반 표현으로 쓴다.

  · 수입: 테슬라모델Y·테슬라모델3·벤츠E클래스·BMW5시리즈·BYD차·**아우디차**·**벤츠차**·**BMW차**·

- **인물 버킷**(제목 주인공이 사람일 때): 머스크·손흥민·블루메(포르쉐 CEO)·왕촨푸(BYD 회장).
  없는 인물이면 소속 브랜드 차/본사사옥/발표행사로 대체.
- **상황 버킷**: 공장생산(생산라인)·본사사옥·발표행사(공개·기자회견)·노조시위(파업·집회).
- 모델 버킷이 없는 차면 테마 카테고리(신차출시/전기차친환경/…/셀럽차)로 폴백.
- **제목·본문의 차종(SUV/세단/미니밴)과 사진이 어긋나지 않게** 맞춘다. (셀럽차는 SUV=에스컬레이드류, 세단=렉서스류 보유)

### 카드별 필수 필드
- `thumbnail`: line1, line2, photo_category, (선택 accent_words)
- `stock_thumbnail`: line1, line2, price, delta, down(true=파랑/false=빨강), logo, (선택 accent_words)
- `photo_card`: eyebrow, headline_lines[], photo_category, (선택 number/number_unit/delta/direction/logo/credit)
- `number_card`: eyebrow, number, number_unit, headline_lines[], (선택 delta, direction[up=빨강/down=파랑], note, logo)
- `bar_card`: eyebrow, title_lines[], categories[], values[], (선택 highlight 인덱스, note)
- `rank_card`: eyebrow, title_lines[], items[[label,value],...], (선택 note)
- `summary_card`: eyebrow, title_lines[], points[], (선택 note)
- 색 규칙(한국식): 상승/긍정 = 빨강(up), 하락/부정 = 파랑(down).
- 데이터카드의 숫자는 반드시 본문에 인용된 소스 근거 수치만 쓴다(창작 금지).

### 카테고리 → photo_category 매핑
| PROMPT 카테고리 | photo_category |
|---|---|
| 신차·출시 | 신차출시 |
| 전기차·친환경 | 전기차친환경 |
| 자동차산업·수출 | 산업수출 |
| 리콜·안전·정책 | 리콜안전정책 |
| 모터스포츠·이슈 | 모터스포츠 |
| 중고차·시장동향 | 중고차시장 |
| 브랜드·기업이슈 | 브랜드기업 |
| 셀럽·연예인차 | 셀럽차 |
※ photo_category만 지정하면 빌더가 해당 폴더에서 순환 선택(중복 회피)한다. 파일명 직접지정 불필요.

### 로고 사용 규칙 (assets/tickers/index.json)
- 기사가 특정 종목을 정면으로 다룰 때만 그 종목 로고 파일명을 카드 `logo`에 넣는다.
  예: 현대차→hyundai_0.png, 기아→kia_1.png, 테슬라→tesla_0.png, BYD→byd_0.png …
- index.json에 후보가 있는 21종만 사용. **제네시스는 로고 미보유 → logo 생략**(수동 추가 전까지).
- 그 기업이 블로그를 후원·보증하는 것처럼 보이게 배치하지 않는다.

## 빌드·검증·커밋
```
python _engine/build_posts.py _engine/articles.json {MMDD}
```
- 결과: output/{MMDD}/{순번}/ 에 0번 본문.txt + N번 사진.jpg
- ★ 빌드 **마지막 줄**을 반드시 볼 것. `규격 위반 없음 — 전 기사 통과` 가 아니면
  `!!!!` 배너에 위반 목록이 뜬다. 뜬 기사는 **재작성 후 다시 빌드**한다(그냥 커밋 금지).
  검사 항목: 이미지 8장 / 실내 2장 이상 / 데이터카드 최대 1장 / 정리카드 최대 1장 /
  1번이 썸네일 / 문단 길이 / 캡션-사진 불일치 / 빈약한 버킷.
- build_report.json 의 각 항목 problems 가 [] 인지도 확인(배너와 같은 내용).
- 로컬 저사양/불안정 RAM 대비: 환경변수 RENDER_CONCURRENCY 로 동시 렌더 수 조절(기본 3, 불안정하면 1).
- assets/photos 는 .gitignore 대상이므로, output 커밋과 별개로 신규 검수 사진 추가 시 `git add -f`.
